# RepurposeAI

Turn one content into every format - tweets, LinkedIn posts, newsletter, and threads.

## Quick Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and sign up with GitHub
2. Import this repo: https://github.com/new/import?repo=repurpose-ai
3. Deploy (default settings work)

## Or Deploy from CLI

```bash
npm i -g vercel
vercel login  # use jdbyrdai@gmail.com
vercel
```

## Development

Currently static HTML. To add real AI:

1. Get an OpenAI API key
2. Add API endpoint that calls OpenAI
3. Connect Stripe for payments
